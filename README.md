# Atlas da Medicina Veterinária — IFFar Frederico Westphalen

Versão estática do Atlas: indicadores acadêmicos e financiamento da oferta, 2018–2026.

Produto de pesquisa independente. Não constitui publicação homologada pelo IFFar. Dados ausentes são ND; rateios financeiros são estimativas condicionais. Os pontos do mapa representam sedes municipais.

Consulte Método e fontes no site para a procedência e as limitações. Esta publicação contém apenas arquivos de produção e dados agregados, sem microdados individuais.
